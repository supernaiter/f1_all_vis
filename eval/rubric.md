# Evaluation Rubric

## Functionality (weight: 0.25)
- Does it fulfill all acceptance criteria in plan.md?
- Are edge cases handled?
- Are error states handled gracefully?

## Craft (weight: 0.25)
- Is the code clean and well-structured?
- Are there appropriate error boundaries?
- Is performance acceptable (no obvious N+1 queries, no blocking renders)?
- Are there no console errors or warnings?

## Design Quality (weight: 0.25)
- Is the layout visually balanced?
- Is typography consistent and readable?
- Is whitespace used effectively?
- Does it work on mobile (375px)?
- Does it work on desktop (1280px)?

## Originality (weight: 0.25)
- Does it have a distinct visual identity?
- Would a human designer recognize it as AI-generated?
- Are there creative choices beyond the default template look?
- Score ≤ 40 if it looks like any generic AI output.

## Project-Specific Criteria
- 1080x1080でSNSフィードに映えるか
- データのhierarchyが3秒で読み取れるか
- F1公式 / The Race / StatsF1 の品質水準に近いか
- レスポンシブ対応（モバイルでの視認性）
