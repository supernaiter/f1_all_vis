  evaluator-contract.md のテンプレートを読む

    - verification_criteria: タスクの検証基準
    - verification_type: TYPE A/B/C/D
    - type_specific_instructions: タイプ別セクションから取得
    - artifact_paths_or_commands: GENERATORの FILES_CHANGED + 補足
  Agent(model: "sonnet", prompt: 埋めたテンプレート) で派遣
  結果から VERDICT と EVIDENCE と SUMMARY を抽出

  ## 4. PM判定
  IF VERDICT == PASS:
    task.status = PASS
    task.summary = GENERATORのRESULT（1文）
    タスクツリーを再評価:
      - 不要になったタスクを削除
      - ブロック解除されたタスクを更新
